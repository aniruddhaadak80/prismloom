# Contributing

Thanks for improving PRISMLOOM! Please:

1. Fork & create a feature branch.
2. Run `bun run typecheck && bun run lint && bun run test && bun run build`.
3. Keep PRs focused; match the existing style.
4. Add tests for new behavior where reasonable.
